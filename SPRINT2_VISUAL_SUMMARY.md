## 📐 Design System

### Spacing (8px Grid)
```
--space-1:  8px   ■
--space-2: 16px   ■■
--space-3: 24px   ■■■
--space-4: 32px   ■■■■
--space-5: 40px   ■■■■■
--space-6: 48px   ■■■■■■
```

### Border Radius
```
--radius-sm:  8px   ╭─╮
--radius-md: 12px   ╭──╮
--radius-lg: 14px   ╭───╮
```

### Shadows
```
--shadow-sm:  ▁      (Very subtle)
--shadow-md:  ▂▁     (Card default)
--shadow-lg:  ▃▂▁    (Modal/popup)
--shadow-hover: ▃▂▁  (Hover effect)
```

### Typography (Inter Font)
```
h1: 2rem    (32px)  Heavy   600
h2: 1.75rem (28px)  Bold    600
h3: 1.5rem  (24px)  Bold    600
h4: 1.25rem (20px)  Medium  600
p:  1rem    (16px)  Normal  400
btn: 0.9375rem (15px) Medium 500
```

## 🔄 Theme Switching

### Visual Transition
```
Light Theme          →          Dark Theme
┌──────────┐                   ┌──────────┐
│ ░░░░░░░░ │                   │ ████████ │
│ ██████████│                   │ ░░░░░░░░ │
│          │  300ms smooth     │          │
│ #F5F7FB  │  ──────────→      │ #111827  │
│          │  transition       │          │
│ Cards:   │                   │ Cards:   │
│ #FFFFFF  │                   │ #1F2937  │
└──────────┘                   └──────────┘
```

### Storage
```
localStorage.setItem('theme', 'light|dark|system')
                                    ↓
              Persists across page reloads
                                    ↓
            Applies on next visit instantly
```
